# 安排

安排侧栏分为「本地」和「系统安排」。「本地」管理用户创建的执行规则；「系统安排」呈现 Desk 的后台维护任务。安排决定何时运行，结果保存在本机。

## 创建与执行

在「安排 → 本地」选择新建，可让 Desk 帮助创建，也可手动设置。说明执行内容，选择执行身份，再设置时间。默认身份为 Desktron；也可使用已有飞书 Bot 的执行配置。

支持仅手动、指定日期时间、固定分钟间隔、每天、工作日、每周及自定义重复。自定义重复按日、周或月设置间隔及日期范围。时间按本机时区计算。

保存前可以试运行；保存后可以立即运行、暂停、恢复或删除。试运行不会替用户创建一条永久安排。已过期的单次安排需要先修改日期，才能重新启用。

## 结果与失败

查看每次运行的状态、结果和错误。绑定 Bot 只复用执行配置，不自动建立飞书消息触发，也不自动向飞书外发结果。

安排由本机 Desk 进程调度。进程退出期间无法正常触发；重启后仍标为运行中的记录会记为中断。当前保留最近 200 次运行记录，不作为永久审计库。

系统安排有各自的维护用途与控制项，不能按普通安排的时间规则推断其行为。涉及记忆维护时，参见[知识、技能与记忆](knowledge-memory.md)。
