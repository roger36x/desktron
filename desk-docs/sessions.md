# 会话与协作

Desk 支持 Claude Code、Codex 和 Pi Coding。引擎和模型共同决定本轮用什么能力执行。

## 开始与继续

在工作流中创建会话，检查引擎和模型。Desk 展示回答、工具执行、等待输入和完成状态。普通会话使用引擎原生历史；Shepherd 会话以统一归档保存可校验的历史。不同引擎的登录方式和可用模型不相同，具体状态从「设置 → AI 引擎」查看。

没有工作流归属的会话显示在侧栏「聊天」组。右键组标题或点击旁边的「…」，选择「新建会话」即可按当前引擎创建无归属会话；该菜单不提供 Resume 找回列表。

右键会话行选择「删除会话」会在确认后永久删除历史和相关记录，不只是从列表移除。正在执行或压缩的会话须先结束当前操作；删除失败时保留原行。若菜单中有「关闭进程」，该动作仅释放进程，不删除历史。

会话与任务分别管理。可以围绕同一任务开多个会话，也可以在一个会话中处理多项任务。重新打开历史会话时，先核实当前目录、分支和最近结果，再执行后续动作。

## 待发消息与撤回

当前回合执行时可以继续输入。待发正文和附件保存在当前浏览器，回合结束后由页面级调度器合并为下一轮发送；切换到其他会话不会停止调度，但关闭整个页面或系统冻结期间不保证续发，恢复后会先核对回执。

点击待发项或使用上键可以取回队尾编辑，并暂停其余消息。删除待发项只影响尚未派发的内容。Esc 在当前输入尚未产生输出且没有其他待发项时尝试撤回；否则中断当前回合。执行结果未知、撤回尚未收口、附件缺失或配置变化时，Desk 不会自动续发，也不会凭失败提示重放请求。

## Shepherd 连续会话

引擎菜单中的 Shepherd 是会话模式，不是另一个模型。启用后创建的会话可以在 Claude、Codex、Pi 之间切换，保留同一个公开会话；目标引擎先追平已确认的历史，再开始工作。普通会话不会因此被转换。

新建 Shepherd 会话默认沿用上次在 Shepherd 中选择的执行引擎，以及该引擎最近保存的模型、effort 和自动压缩配置；创建入口显式指定引擎时，以本次选择为准。已有会话保留各自配置，不随其他会话更改。业务角色与授权不作为全局默认继承。

Shepherd 经 Claude 执行时需要锁定版本的 Claude Agent SDK。安装、更新和同步 Desk 时会自动准备。离线导致准备失败时，可在终端运行 `shepherd prepare-claude` 补装，再运行 `shepherd status` 检查依赖。登录仍使用本机 Claude Code。PATH 上若有无法直接启动的残缺 `claude`，Desk 会跳过它并在日志中记录。

Shepherd 的 Claude 会话进程恢复时只拿到一份不能续期的登录令牌副本，几个小时后可能报 `OAuth token revoked` 或 401。可以改用一年期令牌。macOS／Linux 在终端运行 `python3 "$HOME/.local/share/desktron/home/desktron/lib/claude_token.py" login`（自定义安装时替换路径），它会启动 `claude setup-token`，由本人在浏览器确认授权。保存后会发送一次最小模型请求验证令牌，并非离线检查。成功后按[重启边界](settings.md#更新与生效)明确批准重启。

自动获取失败时，可自行运行 `claude setup-token`，再以相同 Python 命令将 `login` 改成 `set`，在不回显的提示中粘贴令牌。`set` 只保存，不发送模型请求；需要验证时再显式使用 `verify`。不要把令牌写入命令参数或会话正文。令牌保存在 `~/.config/desktron/claude-oauth-token`，只供 Shepherd 的 Claude 会话使用，不进入 Agent 执行命令的环境。使用长期令牌时，这些会话不能使用 claude.ai 连接器和远程控制；到期后重新生成即可。以相同 Python 命令将 `login` 改为 `status`，可以只读查看是否已配置。Windows 使用对应安装路径和托管 Python，以上 POSIX 命令不直接适用。其他引擎也需先完成自身安装和登录。

执行中不能切换。若提示“原生终态未确认”，不要反复发送同一句请求或清空状态；先核验执行记录，避免重复执行工具。切换中断后再次选择原目标引擎，可恢复已确认的进度。

可用 `/compact` 主动压缩上下文。原生自动压缩有一次有限的额外时间预算，避免因前段任务耗时而立即超时；反复进入压缩不会无限续期。压缩成功后保存新的工作上下文，完整归档仍保留；失败或取消不覆盖旧检查点。

“长时间没有进展”是观察提示，不等于失败。心跳、连接数据和重复队列消息也不等于模型在推进；排队等待与整轮执行各有上限。“达到最长时限”可能发生在刚有输出之后，出现“终态未确认”时先核对操作结果，不直接重发。

三种引擎都支持在已知上下文预算不足时，自动使用旧摘要和最多最近 12 回合的文本继续；窗口越小，保留内容越少。界面会提示降级，完整历史仍可检索。三引擎没有窗口信息或明确预算时仍保留原生准入。

Shepherd 保留完整、经过来源校验的公共历史；压缩或小窗口降级后，Agent 可先搜索候选，再按预算读取命中附近的回合。历史工具调用只作为证据，不会再次执行。当前实现覆盖部分跨引擎工具图片迁移，具体受目标引擎和检查点格式限制；不能假定所有图片或附件组合均可迁移。回退仍不开放。

已完成回复下方的「分支」可创建独立 Shepherd 会话，沿用当前选择的引擎、模型设置和工作流；只复制到所选回复，原会话保持不变。分支的历史经来源校验后独立保存，删除原会话不会删除分支历史；不重跑历史工具，也不继承已授予的权限。执行、切换或恢复未完成时拒绝分支。

右键删除 Shepherd 会话会清除该会话的公共历史、私有原生记录、检查点、输入、回执和检索缓存，不可恢复。系统仅保留一条不含正文的会话 ID 删除标记，用来拒绝迟到请求，避免已删除会话被网络重试重新创建。删除会话不会撤销此前已经发生的文件修改、命令或外部平台操作。

## 授权与中断

用户中断会停止当前回合，并请求取消该会话的 Pi 异步子代理，抑制中断前未送达的结果；已发生的工具或外部操作不会撤销。结果通知规则见[子代理与结果通知](subagents.md)。

工具请求输入或授权时，按界面提示处理。授权作用于具体动作；另一段会话或消息不能代替用户批准。重启 Desk 会中断当前进程中的会话和终端，不能用重启代替故障调查。

## 跨会话协作

Agent 可以通过 `desk-msg list` 查看可达会话，单向交接使用 `send`。`desk-msg ask <会话> "问题或关键词"` 直接读取稳定历史并返回带引用的材料，由当前会话回答，不启动目标模型、不排队、不创建 mailbox；默认及最大读取时限为 5 秒，超时终止独立读取进程。

Shepherd 结果绑定一个 `head_seq/head_hash`，跳过正在执行的回合，返回经来源校验的用户／助手文本。最近回合与已有索引命中共同选材；索引缺失、落后、原文不可用或截断会通过 `partial/warnings/coverage` 显式报告，请求内不重建索引，正常回合收口后在后台增量刷新。普通引擎会话只读取近期已收口的 Desk 消息投影，引用包含消息 ID 与快照 hash，不等同于完整原生归档。默认不导出工具参数、工具输出、思考、图片或附件。

材料是历史证据，不是目标 Agent 的新回复或用户授权。无命中不能推断为没有讨论过。旧版已发出的问询继续用 `desk-msg wait <请求号>` 领取；新 `ask` 没有后台回复。

## 会话名称

侧栏右键可以重命名会话。Agent 使用 `desk-session rename "新名称"` 修改当前会话；操作其他会话时增加 `--session <会话 ID>`。名称由 Desk 统一保存，下一回合开始前再同步给支持原生命名的执行引擎，不会额外触发模型回合。

## 项目记忆

会话默认携带当前工作流完整项目模型、更新时间和检索入口，不再提供独立记忆摘要。需要原始依据时按需检索；人物关系和依赖从图谱检索。记忆写入规则见[知识、技能与记忆](knowledge-memory.md)。
