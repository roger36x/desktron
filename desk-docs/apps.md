# 应用

应用页集中管理可以重复打开的工具。左侧「全部／官方／本地」按来源筛选；官方清单与用户创建的条目分别维护。

## 当前官方工具

| 应用 | 用途 |
| --- | --- |
| 备忘录 | 保存工作备忘 |
| Excalidraw | 绘制图形 |
| 终端 | 执行命令和交互操作 |
| 浏览器 | 打开网页 |
| Monaco IDE | 编辑文件 |
| 文件浏览器 | 浏览目录与文件 |
| TaskNote | 组织文本任务 |

以上 7 项来自当前官方清单；工具是否可用仍取决于本机依赖、权限和当前版本。

TaskNote 沿用原 TaskPaper 的应用标识和任务数据，当前图标为暖白纸底与三个小红勾。
Timeline 已从官方应用清单移除；此调整不删除飞书事件数据，也不停止系统安排中的同步服务。

## 本地应用

本地应用可以是 HTML 工具，也可以是带参数的 Agent 任务入口。任务入口收集参数并启动执行，不等于固定时间自动运行；定时需求在安排中管理。

更新已有应用应保留其稳定标识，避免重复注册。删除条目前先确认其关联材料是否还被其他工作使用。

## 分享与操控

工作台应用是可复用条目。统计页、看板和演示材料需要分享时，应构建独立页面并通过发布流程获得预览链接；发布需要授权。

应用能否被 Agent 操作取决于声明的能力和控制接口，不因嵌入 Desk 就自动开放全部操作。见[浏览器操控](browser-control.md)与[扩展与贡献](extend.md)。
