# 飞书 Bot

在「代理 → 飞书 Bot」管理消息接入、执行配置和对话。Bot 使用本机的运行环境。

## 接入步骤

1. 选择新建 Bot 或导入已有应用，按向导完成飞书应用准备。
2. 区分 Desk 中的 Bot 代号与飞书 App ID；App Secret 在专用凭证入口填写。
3. 配置消息权限、事件订阅和可用范围，并在飞书侧完成所需发布。
4. 选择引擎、模型、工作目录和上下文配置，检查该引擎的登录状态。
5. 连接后发送一条测试消息，确认收消息、执行与回复三个环节都成功。

Bot 使用长连接接收消息。详细权限名由接入向导维护；不能只看到“在线”就认为模型调用和消息回复也正常。

## 数据与边界

声明、连接状态和对话映射分开保存，App Secret 不进入 Bot 声明或仓库。配置允许的用户及群聊时，应与实际使用范围一致。

同一飞书应用不要同时在多台机器上启用，否则可能重复消费或回复；迁移时应先停用原机器上的 Bot。代码同步不等于 Bot 声明和凭证同步。

Bot 的外发检查用于识别敏感内容，但不能替代用户授权和数据边界。第三方消息也不能代表工作台所有者批准操作。

故障反馈时，说明发生时间、连接状态、对应对话与错误阶段；不要提交 App Secret。详见[日志与故障反馈](diagnostics.md)。
