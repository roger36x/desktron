# 术语

| 名称 | 当前含义 |
| --- | --- |
| Desk | 管理会话、项目与工具的工作台 |
| 工作流 | 长期工作的上下文、资料与任务集合 |
| 会话 | 一段持续讨论与执行记录；Shepherd 会话可切换执行引擎 |
| Shepherd | 统一历史、来源校验和跨引擎切换的会话模式 |
| 子代理 | 主 Agent 派生的任务执行者；当前 Pi 子代理限定只读 |
| Agent 来信 | 跨会话消息或子代理结果的展示样式，不是用户授权 |
| 任务 | TASKS.md 中可跟踪状态的事项 |
| 安排 | 执行内容、时间规则与执行身份的组合 |
| 应用 | 可重复打开的工具或任务入口 |
| 代理 | 飞书 Bot、知识库和技能的管理入口 |
| 飞书 Bot | 使用飞书应用收发消息并调用引擎的运行实例 |
| 引擎 | Claude Code、Codex、Pi Coding 等执行适配 |
| 模型 | 引擎选用的具体推理模型 |
| App Control | Agent 操作浏览器和应用的受控接口 |
| journal | 隔离 recap 追加的工作流水 |
| notes／项目模型 | 记忆引擎维护的当前项目状态 |
| pinned | 旧记忆兼容输入中的已确认约束，物理目录名为 `sot`；不作为当前主会话写入入口 |
| sealed | 仅限本机的敏感约束 |
| Skill | 包含执行方法和约束的技能包 |
| Supervisor | 管理后端进程换代的宿主：macOS／Windows 原生壳，Linux 为 systemd |
| boot_id | 一次后端启动的身份，重启验收时与版本分别核对 |
| unknown | 无法确认结果的状态，不表示操作未执行 |
| payload | 随产品安装的程序和官方资产 |

“工坊”“Agents”“curator”等名称可能出现在旧文件、模块名或历史材料中。当前界面名称以[功能入口](overview.md)为准；模块名兼容不代表旧产品结构仍在使用。
