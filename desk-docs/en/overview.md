# What Desk can do

Desktron brings AI sessions, project materials, and reusable tools into one workbench. Engines carry out tasks; Desk manages session entry points, runtime state, the organization of materials, memory, and interaction authorization.

## Features and entry points

| What you want to do | Entry point | What you get |
| --- | --- | --- |
| Continue a discussion across engines | Shepherd sessions | Unified history, switching among three engines, compaction, and search |
| Submit follow-up requests in a row | The send queue in the session input area | Editing, pausing, withdrawing, and follow-up sends after receipt verification |
| Dispatch read-only subtasks | Subagents in Pi sessions | Status details, result messages, unified time limits, and interruption/cancellation |
| Keep a project moving | Workflows and their sessions | Project background, code repository references, tasks, and conversations |
| Track to-dos | Workflow tasks, the Tasks page | Status and details from the same TASKS.md |
| Repeat work | Arrangements → Local | Time rules, the identity that runs it, and run results |
| See background maintenance | Arrangements → System | Status of system jobs and their controls |
| Use tools | Apps → All / Official / Local | Tools and apps you can open repeatedly |
| Connect Feishu messages | Agents → Feishu Bot | Bot connection, execution settings, and conversation records |
| Use knowledge and skills | Agents → Knowledge / Skills | Mount status, install source, version, and usage records |
| Verify public web pages | Agent web tools / browser | Anonymous search and fetching, or authorized operation of logged-in pages |
| Configure the environment | Settings | Engines, tools, usage, and diagnostics |

Arrangements, Apps, Agents, and Settings open as dialogs with a sidebar. Choose a category on the left and work on the right; closing returns you to where you were.

## Three distinctions

Workflows organize long-term material, sessions hold one ongoing discussion, and tasks represent things to get done; they do not need to map one to one. Apps are reusable tools, arrangements decide when something runs, and Bots provide a message entry point and execution settings.

Desk runs on this machine, and materials, credentials, and run records are all stored locally. It is intended for personal use; remote diagnosis across users is not available yet.
