# Desktron User Guide

This guide describes Desk's current entry points, data ownership, and usage limits. Actual availability depends on the installed version and the checks on the settings page.

The Chinese guide one level up (`../00-index.md`) is the reference text; when the two differ, the Chinese version prevails.

## Getting started

- [What Desk can do](overview.md): overview of features, page entry points, and limits.
- [First-run setup](first-run.md): prepare this machine and sign in to engines and tools.
- [Workflows and tasks](workflows.md): organize projects, code repositories, tasks, and materials.
- [Sessions and collaboration](sessions.md): the three engines, Shepherd, the send queue, compaction, interruption, search, and renaming.
- [Subagents and result notifications](subagents.md): Pi subtasks, asynchronous messages, time limits, and cancellation.

## Managing reusable capabilities

- [Arrangements](arrangements.md): manual runs, scheduled runs, and run records.
- [Apps](apps.md): official tools, local apps, and how to open them.
- [Feishu Bot](agents.md): connection, where it runs, and troubleshooting.
- [Knowledge, skills, and memory](knowledge-memory.md): knowledge bases, skill sources, the project model, and manual constraints.
- [Browser control](browser-control.md): verifying public web pages, isolated tabs, logged-in pages, and the built-in browser.

## Maintaining Desk

- [Settings and updates](settings.md): configuration, usage, upgrades, where settings take effect, and restarts.
- [Network and proxy](network-proxy.md): unified proxy configuration on Windows, port tests, and scope.
- [Logs and fault reports](diagnostics.md): capture the scene and tell implementation problems from environment problems.
- [Extending and contributing](extend.md): create workflows, apps, and skills.
- [Glossary](glossary.md): standard names and what the data means.
- Execution references: [Task data format](reference/task-format.md), [Task completion evidence](reference/task-evidence.md), [App Control contract](reference/app-control.md).

Development, testing, releases, and historical decisions are in `docs/00-index.md` in the source repository; that directory is not shipped with the product.
