# Desk 能做什么

Desktron 把 AI 会话、项目材料和可复用工具放在同一工作台。引擎执行任务，Desk 管理会话入口、运行状态、资料组织、记忆和交互授权。

## 功能与入口

| 要完成的事 | 入口 | 得到什么 |
| --- | --- | --- |
| 跨引擎继续讨论 | Shepherd 会话 | 统一历史、三引擎切换、压缩与检索 |
| 连续提交后续要求 | 会话输入区的待发队列 | 编辑、暂停、撤回和回执核验后的续发 |
| 分派只读子任务 | Pi 会话的子代理 | 状态详情、结果来信、统一时限及中断取消 |
| 持续推进项目 | 工作流及其会话 | 项目背景、代码仓引用、任务和对话 |
| 跟踪待办 | 工作流任务、任务页 | 同一份 TASKS.md 的状态与详情 |
| 重复执行工作 | 安排 → 本地 | 时间规则、执行身份、运行结果 |
| 查看后台维护 | 安排 → 系统安排 | 系统任务的状态与操作入口 |
| 使用工具 | 应用 → 全部／官方／本地 | 可重复打开的工具和应用 |
| 接入飞书消息 | 代理 → 飞书 Bot | Bot 的连接、执行配置与对话记录 |
| 使用知识和技能 | 代理 → 知识库／技能 | 挂载状态、安装来源、版本和使用记录 |
| 查证公开网页 | Agent 网页工具／浏览器 | 匿名搜索与抓取，或经授权操作登录态页面 |
| 配置环境 | 设置 | 引擎、工具、用量和诊断 |

安排、应用、代理和设置采用带侧栏的弹窗。左侧选择类别，右侧处理内容；关闭后回到原工作位置。

## 使用时的三个区别

工作流组织长期材料，会话承载一次持续讨论，任务表示要完成的事项；三者不要求一一绑定。应用是可复用工具，安排决定何时执行，Bot 提供消息入口和执行配置。

Desk 在本机运行，资料、凭证和运行记录都保存在本机。它面向个人使用；跨用户远程诊断尚未提供。
